# Docker API 实机验收 — 0.2.0

[English](SERVICE_VALIDATION.md) | [简体中文](SERVICE_VALIDATION.zh-CN.md)

## 实际运行环境

三星 SCV41 / 骁龙 855 上的真实 ARM64 Docker 容器，使用本仓库编译的常驻运行器和已通过验证的优化模型。CPU/GPU 均加载**同一个优化图**，与历史文档中部分旧 CPU 参考图的比较不同。

镜像为 Debian Bookworm、Python 3.11、FastAPI、uvloop/httptools 和 orjson。一个模型进程常驻、启动预热三次；CPU 四线程；GPU 透传 KGSL 设备、设备组及只读 Turnip 驱动。原生进程日志实际识别为 `Turnip Adreno (TM) 640`。

客户端在手机上通过手机接口地址访问 Docker 映射的 HTTP 端口，包含上传、JPEG 解码、letterbox、归一化、推理、排队和 JSON 返回。没有把本地管道测试冒充网络 API；也没有测公网网络、实时截图或目标检测。

## 速度

单图模式每种并发测 16 次，循环四张真实截图；四图批量模式请求四次，共 16 图。动态频率、短时测试，本轮未重新测功耗。

| 后端/模式 | HTTP 平均延迟 | HTTP P95 | 吞吐 |
|---|---:|---:|---:|
| CPU，串行 | 183.44 ms | 194.43 ms | 5.41 图/秒 |
| GPU，串行 | **159.49 ms** | **170.20 ms** | **6.21 图/秒** |
| CPU，四并发 | 730.78 ms | 826.62 ms | 4.95 图/秒 |
| GPU，四并发 | 584.71 ms | 650.90 ms | 6.17 图/秒 |
| CPU，每批四图 | — | — | 5.04 图/秒 |
| GPU，每批四图 | — | — | **6.42 图/秒** |

GPU 串行原生全局特征提取平均 123.65 ms；完整 HTTP 更慢。旧 RAW 测试的 8.23 FPS 不能标成 API 吞吐。四并发增加排队，不能当成单 GPU 同时运行四个模型实例。

## 精度和验收

四张图使用 API 完全相同的预处理，与官方 FP32 ONNX 对照：GPU 特征平均余弦 **0.999951677**、最小 **0.999937975**；CPU 在数值精度下接近 1。这只是小规模特征保持验证，不是标注检测准确率。

真实容器通过：健康检查、Bearer 鉴权、缺失/异常密钥 401、768 维归一化特征、四图 base64 批量、同图相似度、非法图片 422、九图批量 422、OpenAPI、串行和四客户端请求。请求 GPU 而未透传设备/ICD 时启动失败，没有回退 CPU。代码也拒绝 CPU 软件 Vulkan 设备，但未单独切换软件驱动做实机测试。

Docker inspect 核对运行用户 **10001:10001**、非 privileged、只读根目录。没有停止原有手机应用。八项协议/接口单元测试另覆盖请求体限制、队列溢出、子进程失败/回收和超时后的管道帧对齐；单元测试使用协议替身，不是硬件加速证据。

## 发布证据

`results/service/acceptance.json` 保存实际聚合数据和精度结果；`image.json` 保存实测 ARM64 镜像 ID、归档 SHA256 和大小。预编译镜像使用本地交叉编译的开源运行器，通过 `service-prebuilt` 目标构建；从源码完整构建目标另由 CI 检查。

已检查镜像归档：ARM64、默认非 root、没有模型文件或内置 API 密钥。权重和驱动只读挂载；密钥和私有部署路径不公开。镜像不含游戏素材或 Qualcomm SDK。独立 AMD64 源码镜像构建以 CI 结果为准，ARM64 实测不代表任意平台都已验收。

独立的 [AMD64 完整源码镜像构建](https://github.com/q1820926174-cpu/dinov3-snapdragon-855/actions/runs/40850232246) 已通过，包含运行器加载及镜像非 root 检查；[Linux 接口/协议测试](https://github.com/q1820926174-cpu/dinov3-snapdragon-855/actions/runs/40850232371) 也通过。AMD64 CI 没有运行需授权的模型或物理 GPU，不能扩大 ARM64 实机结论。
